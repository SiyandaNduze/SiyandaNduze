## Featured Projects

### 🚀 [M.A.R.S. — Multi-Agent Reasoning System](https://github.com/SiyandaNduze/M.A.R.S)

**A JARVIS-inspired, voice-first personal AI assistant for Windows.**

M.A.R.S. combines natural-language interaction with a modular tool system, desktop orb interface, and voice input/output to help perform useful tasks directly from a Windows computer.

**Highlights**
- Wake-word activation with speech-to-text and neural text-to-speech.
- 50+ tools covering tasks, files, web search, browser and desktop automation, notes, memory, and more.
- Browser automation with Playwright and native Windows UI automation with pywinauto.
- Multi-provider model rotation and fallback handling.
- Desktop orb UI with live listening, thinking, and speaking states.
- Voice confirmations for consequential actions.

**Tech stack:** Python · Groq · OpenRouter · Ollama · Whisper · Piper TTS · Playwright · pywinauto · Tkinter

### 🤖 [RAGApp](https://github.com/SiyandaNduze/RAGApp)

**Ask questions about your own PDF documents using AI.**

A retrieval-augmented generation application that processes PDFs, creates embeddings, retrieves relevant context, and generates natural-language answers.

**Highlights**
- PDF ingestion, chunking, and embedding workflows.
- Semantic search using Qdrant.
- Background workflows orchestrated with Inngest.
- FastAPI backend and Streamlit user interface.

**Tech stack:** Python · FastAPI · Streamlit · Qdrant · OpenAI · Inngest · LlamaIndex

### 🎓 [Tutor Hire System](https://github.com/SiyandaNduze/Tutor_hire_system)

**A web platform connecting students with tutors.**

A role-based tutoring platform designed to manage tutoring requests, job assignments, notifications, and platform analytics.

**Highlights**
- Student, tutor, and administrator roles.
- Tutoring request and job management.
- Role-based workflows and user dashboards.
- Notifications and usage analytics.

**Tech stack:** C# · ASP.NET Core MVC · .NET 9 · Entity Framework Core · SQL Server · Bootstrap · JavaScript
