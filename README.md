## Featured Projects

###  [M.A.R.S. — Multi-Agent Reasoning System](https://github.com/SiyandaNduze/M.A.R.S)

**A JARVIS-inspired, voice-first personal AI assistant for Windows.**

M.A.R.S. combines natural-language interaction with a modular tool system, voice input/output, and a desktop orb interface.

- Wake-word activation, speech recognition, and neural text-to-speech.
- 50+ tools for tasks, files, web search, browser and desktop automation, notes, and memory.
- Browser automation with Playwright and Windows UI automation with pywinauto.
- Multiple model providers with fallback handling.
- Voice confirmations for consequential actions.

**Technologies:** Python · Groq · OpenRouter · Ollama · Whisper · Piper TTS · Playwright · pywinauto · Tkinter

###  [RAGApp](https://github.com/SiyandaNduze/RAGApp)

**Ask questions about your own PDF documents using AI.**

A retrieval-augmented generation application that processes PDFs, creates embeddings, retrieves relevant context, and generates natural-language answers.

- PDF ingestion, chunking, and embedding workflows.
- Semantic search with Qdrant.
- Background workflows orchestrated with Inngest.
- FastAPI backend and Streamlit interface.

**Technologies:** Python · FastAPI · Streamlit · Qdrant · OpenAI · Inngest · LlamaIndex

###  [Tutor Hire System](https://github.com/SiyandaNduze/Tutor_hire_system)

**A web platform connecting students with tutors.**

A role-based tutoring platform for managing tutoring requests, job assignments, notifications, and analytics.

- Student, tutor, and administrator roles.
- Tutoring request and job management.
- Role-based workflows and dashboards.
- Notifications and usage analytics.

**Technologies:** C# · ASP.NET Core MVC · .NET 9 · Entity Framework Core · SQL Server · Bootstrap · JavaScript

###  [AuthService](https://github.com/SiyandaNduze/AuthService)

**Technologies:** C# · .NET 8 · ASP.NET Core · Entity Framework Core · SQL Server · JWT
